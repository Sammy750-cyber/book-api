# Security Policy

## Scope

This repository contains a demonstration application designed to showcase secure software development and DevSecOps practices.

## Reporting a Vulnerability

If you discover a security issue in this project, please report it privately rather than opening a public issue containing sensitive information.

## Security Practices

The project will progressively implement:

- Dependency vulnerability scanning
- Static application security testing
- Secret detection
- Container image scanning
- Secure environment configuration
- Automated security checks in CI/CD
